# IT-OPS 배포 오류 감지 및 복구 UI

## 실행 방법 (초보자용)

1. Cursor에서 기존 React 프로젝트 폴더를 엽니다.
2. `src/App.js`와 `src/App.css` 파일을 이 폴더의 파일 내용으로 교체합니다.
3. `src/index.js` 또는 `src/main.jsx`에서 `App`을 불러오고 있는지 확인합니다.
4. Cursor 터미널에서 프로젝트 방식에 맞게 실행합니다.
   - Create React App: `npm start`
   - Vite: `npm run dev`

## 구현된 기능
- 화이트 모드 IT 운영 대시보드
- 서비스별 현재 버전과 상태 표시
- 서비스명 검색
- 왼쪽 메뉴 선택
- 배포 오류 및 버전 이력 표시
- 롤백 버튼 클릭 시 확인 모달 표시
- 확인 시 payment-service를 v2.4.1에서 v2.3.8로 바꾸고, 화면에 복구 이력 추가
- 알림 메시지와 복구 후 상태 표시

## 중요
현재는 UI 시연용 프론트엔드입니다. API, 데이터베이스, 실제 배포 파이프라인과 연결되어 있지 않으며 실제 서버를 롤백하지 않습니다. 실제 서비스에서 사용하려면 인증/권한 검사, 백엔드 API, 배포 시스템 연동, 감사 로그, 롤백 승인 및 데이터 호환성 검증이 필요합니다.
